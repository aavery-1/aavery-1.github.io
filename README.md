# Florida School Facilities Explorer

An internal analyst tool for exploring school-facilities data across Miami-Dade,
Broward, and Orange counties. It shows facts on a map. The analyst forms the
judgment. **The tool never scores, ranks, or recommends a site.**

This repository is the runnable front end built from the kit in this folder. The
design and specification live in the numbered docs (`00_BUILD_PROMPT.md` through
`07_LAYERS.config.json`). `07_LAYERS.config.json` is a live input: the layer
panel, legends, deck.gl layers, and inspector rows are all generated from it.

## Stack

React 18, TypeScript, Vite, Google Maps JavaScript API, deck.gl (GoogleMapsOverlay),
turf.js, rbush, Zustand, Vitest. Node 20 LTS, npm.

## Run it

Requirements: Node 20 (an `.nvmrc` pins it; `nvm use` picks it up). npm.

```bash
nvm use            # optional, selects Node 20 from .nvmrc
npm install
cp .env.example .env
# paste your Google Maps JavaScript API key into .env:
#   VITE_GOOGLE_MAPS_API_KEY=your_key_here
npm run dev
```

Open the printed local URL (default http://localhost:5173).

Without a key the app does not crash or blank. It shows a specific setup message,
and the layer panel, grade filter, and tests still work. The base map is the only
part that needs the key.

### Google Maps key notes

- Enable the **Maps JavaScript API** for your Google Cloud project and enable
  billing. The 2025 pricing change is session-based; for a handful of analysts
  the monthly platform credit often covers it. Set a budget alert and a quota cap
  on day one.
- Restrict the key by HTTP referrer before using it anywhere public.
- The key is read at build time by Vite. It is never committed: `.env` is
  gitignored and `.env.example` ships empty.

## Test it

```bash
npm test           # Vitest, runs once
npm run test:watch # watch mode
npm run typecheck  # tsc --noEmit
npm run build      # typecheck + production build
```

The suite enforces the correctness claims (see `05_ACCURACY_STANDARDS.md`):
known-distance within 1%, 5-mile geodesic buffer area within 1% of 78.54 mi²,
latitude invariance, exact-half area-weighted intersection, full grade-domain
rendering, sample-file schema validation, CSV well-formedness, and a scan that
fails on any em dash in the authored files.

## What you can do in the app

- Toggle data layers grouped in the right-side panel (Schools, Demand, Risk,
  Boundaries, Context). Every layer carries source and vintage.
- Filter school pins by current letter grade. Grade is encoded as **color plus
  letter**, always, so it survives colorblindness and grayscale printing.
- Click a school pin (or search by name / MSID) to open the inspector: identity,
  the historic grade timeline with formula-change dividers and no trend line, and
  context rows read from the active layers.
- Pin 2 to 4 sites into compare mode. Rows align across columns. No column is
  ranked. No aggregate score.
- Measure distance and draw an N-mile radius, both geodesically correct. The
  scale bar agrees with the measure tool on any local segment.
- Export the inspector, a compare view, or a radius selection to CSV.

## Sample data

Everything renders from committed sample GeoJSON in `public/data/`, generated by
`scripts/generate-sample-data.mjs` (run `node scripts/generate-sample-data.mjs`
to regenerate). The sample is clearly labeled in the UI. See `PROJECT_NOTES.md`
for what is sample versus real and the ordered plan to wire real sources.

## Project layout

```
src/
  config/     typed loader for 07_LAYERS.config.json
  geo/        the only place distance, area, buffer, and intersection are computed
  data/       types, validators, one adapter per layer, derivations, CSV
  map/        Google base + deck.gl overlay, scale bar, coordinate readout
  panel/      grouped layer toggles, grade filter, legend
  inspector/  school inspector, grade timeline, context rows, compare drawer
  tools/      measure, radius, CSV export
  topbar/     search, county selector, attribution
  errors/     root and map error boundaries
  ui/         small shared primitives and icons
public/data/  committed sample GeoJSON
```
